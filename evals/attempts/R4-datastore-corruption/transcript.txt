=== 7. what the run measured about the injector, not the class ===

The probe sweep (`valkey-cli EVAL <lua> 0 cart \xff\xff\xff\xff`, run once with a correct argv) returned
731: every hash in the store at 07:21:39 was overwritten once. A4 (2026-09-23) measured that a live cart
is written and read back within 5-300 ms; a single sweep lands on none of them, which is exactly what
A4's 5-second sweep measured and why A4b went to 50 ms. R4's loop was meant to be A4b's loop and was a
loop around a no-op. Two further defects found while reading it: the payload `\xff\xff\xff\xff` reaches
the CLI as sixteen ASCII characters, not four 0xFF bytes (A4b's shell wrote a Lua literal); and the
fake-runner tests check what argv the injector builds, not what `sh` does with it - which is the only
place this could have been caught short of running it. Fixed in 0147: positional inputs, a hex payload
decoded in Lua, a heartbeat file the injector reads before it reports the loop running, and a test that
runs the loop under a real `sh`.
