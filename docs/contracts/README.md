# Committed contracts

**What lives here: interface surfaces this repository publishes, in a form a diff can read.**
A contract generated at runtime is a contract nobody reviews — the Phase 2 audit's D5 — so
each one is snapshotted into this directory and asserted by a test. A change that alters the
surface fails that test, and the fix is to regenerate the snapshot **in the same commit that
changes the interface**, where a reviewer sees both halves at once.

| File | Surface | Generated by | Asserted by |
|---|---|---|---|
| `ingest-openapi.json` | `POST /api/v1/alerts`, `GET /healthz` — the platform's public REST contract | `faultline.ingest.app`'s FastAPI app | `tests/test_ingest.py::test_the_rest_contract_matches_the_committed_snapshot` |

## Regenerating

```
make openapi
```

The command rewrites the snapshot from the running app definition. Read the diff before
committing it: an unintended line there is a breaking change to a public interface, which is
exactly what the snapshot exists to make visible.

## Why the ingest surface and not the CLIs

T2.1's deliverable names *"the FastAPI app's generated OpenAPI schema"* as *"the platform's
public REST contract from day one"*. The CLIs (`faultline-eval`, `faultline-migrate`,
`faultline-seed`, the agent and orchestrator entry points) are operator tools whose arguments
are covered by their own tests; nothing outside this repository is written against them. If
that changes, they belong here too.
